# Servicio de Gestión de Clientes, Pagos y Aprobaciones

Este servicio fue diseñado para gestionar información relacionada con clientes, pagos y aprobaciones, proporcionando una solución eficiente para almacenar, procesar y analizar datos.

## Instalación de Dependencias

1. Clonar el repositorio del proyecto:
  ```bash
  git clone https://github.com/Ace56882020/Billetera
  cd wallet-service-db
  ```

2. Instalar las dependencias necesarias:
  ```bash
  npm install
  ```

## Ejecución del Servicio

1. Configurar las variables de entorno necesarias en un archivo `.env`.

2. Iniciar el servicio:
  ```bash
 npm run start:dev
  ```
