# ePayco Wallet

ePayco Wallet es una aplicación web desarrollada con React que permite gestionar y visualizar tu saldo, movimientos y realizar transacciones de manera sencilla y segura.


## Instalación

Sigue estos pasos después de clonar o descargar el repositorio:

```bash
# Instala las dependencias del proyecto
npm install
```

## Ejecución

Para iniciar la aplicación en modo desarrollo, ejecuta:

```bash
npm start
```

Esto abrirá la app en [http://localhost:3000](http://localhost:3000).

## Comandos Disponibles

- `npm start`: Inicia la aplicación en modo desarrollo.
- `npm test`: Ejecuta los tests en modo interactivo.
- `npm run build`: Genera una versión optimizada para producción.
- `npm run eject`: Extrae la configuración de Create React App (irreversible).
