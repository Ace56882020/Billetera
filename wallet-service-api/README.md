## Resumen

Este proyecto es un servicio API que permite la conexión con un cliente web, proporcionando una base eficiente y escalable para aplicaciones del lado del servidor.

## Instalación

```bash
# Instalar dependencias
$ npm install
```

## Ejecución

```bash
# Modo desarrollo
$ npm run start

# Modo watch
$ npm run start:dev

# Modo producción
$ npm run start:prod
```

## Documentación API

Este proyecto utiliza Swagger para generar documentación interactiva de la API. Una vez que el servidor esté en ejecución, puedes acceder a la documentación en la siguiente URL:

[http://localhost:4001/api#/](http://localhost:4001/api#/)
